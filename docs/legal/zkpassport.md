# zkPassport 專門聲明（預留，功能尚未上線）

版本 1・生效日期 2026-11-05

## 重點摘要

- **zkPassport 相容功能目前尚未上線。** 本文件說明未來預計採用的第三方零知識證明流程；本 App 不因展示此文件而立即提供或啟用該功能。
- 依目前規劃，zkPassport 的傳送服務、電路與憑證包下載、區塊鏈查詢等，由第三方營運，可能看見你的 IP 位址、連線時間及部分請求中繼資訊。
- 預計不支援官方 App 專用的 FaceMatch 或加鹽唯一識別碼證明；未加鹽識別碼可能在同一服務內持續相同，並非完全不可關聯。
- 不同意時不使用 zkPassport 服務；電子護照的 NFC 讀取及本機驗證若由其他功能提供，不受影響。正式上線前應重新確認實際資料流及本聲明內容。

## 1. 預計功能與現況

zkPassport 為第三方提供的電子護照零知識證明協定及相關服務。依本專案目前規劃，未來可使用 NFC 讀取的電子護照資料，針對年齡、國籍等條件產生或查驗特定零知識證明，而非在每次證明時直接傳送完整護照內容；亦可能產生 zkPassport 請求以查驗他人。

**上述整合尚未正式提供。** 功能與介面若有新增、修改、擴大資料傳送或調整第三方提供者，應在上線前修訂聲明並取得相應同意，不能依未實現的設計向使用者保證安全性。

## 2. 預計營運者及資料流向

如依目前規劃實作，可能涉及：

- **傳送服務（如 `bridge.zkpassport.id`）：** 在請求者與回應者間轉送請求或證明。若端對端加密確實啟用並經驗證，服務通常無法直接讀取受保護的證明內容，但仍可能觀察 IP 位址、連線時間、會話識別碼與傳輸大小；未驗證前不能保證所有內容均不可見。
- **電路、憑證包及制裁清單下載：** 下載伺服器可能記錄你的 IP 位址與取得的資料種類，並據此推知護照發行國、簽章演算法或驗證情境。
- **公開以太坊節點：** 透過節點查詢電路、憑證樹或註冊合約；節點營運者可能知道查詢位址、時間與合約。
- **可選的線上查驗 API：** 只有你另行啟用、且符合實際設定的觸發條件時，才可能向第三方傳送整份證明及相關結果；依目前規劃預設停用。
- **可選的雲端證明服務：** 如某類壓縮證明需要第三方計算，只有你確認該次請求後，才可能送出必要的子證明或計算資料；依目前規劃不預設啟用。子證明未必等於護照原始資料，但仍可能含可識別資訊。

實際的第三方名稱、端點、資料可見性、安全機制與保存期限，以上線版本、服務條款及經測試的封包流程為準。

## 3. 隱私、唯一識別碼及驗證限制

- **FaceMatch：** 依目前相容規劃，本 App 不支援只能由 zkPassport 官方 App 產生的 FaceMatch 證明；要求該功能的請求無法由本 App 完成。
- **加鹽識別碼：** 依目前規劃不支援需要官方機制產生的加鹽唯一識別碼；未加鹽的識別碼可能由護照相關資料、網域與用途推導，在相同服務脈絡下保持一致，因此有跨次關聯風險；知悉完整晶片資料的主體亦可能推導相關結果。
- **請求者身分：** 請求中的網域或識別資訊可能由請求建立者提供；本 App 規劃比對來源並在不一致時警示，但警示不代表已獨立確認對方真實身分。
- **服務可用性：** 第三方得依其規則變更或停止服務。零知識證明只保證特定電路及驗證條件下的性質，**不等於任何身分或聲明都已獲政府認可**。
