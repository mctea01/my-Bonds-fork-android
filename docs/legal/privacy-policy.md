# DIW MY WALLET 隱私權政策

版本 1・生效日期 2026-11-05

## 重點摘要

- 本 App 不需開發者帳號，沒有廣告、使用分析、當機回報或內建追蹤服務；開發者目前不營運接收錢包證件、文件或使用紀錄的後端伺服器。
- 證件、金鑰、文件、設定及同意紀錄主要儲存在裝置的 App 私有空間並受保護；但主動出示、簽署、查詢或背景驗證等功能，可能把必要資料傳給第三方。
- 部分 HTTP 查詢及 Bonds 格式相容的離線傳輸沒有傳輸層加密；第三方仍可能取得 IP 位址、查詢對象或你同意出示的資料。
- 數位憑證皮夾、Microsoft Entra Verified ID、行動自然人憑證、MyData 等功能須另外選擇啟用。你可撤回各項同意，但已傳出的資料不會因此從第三方刪除。

## 1. 適用範圍及名詞

本政策說明個人開發者林哲全發布的 DIW MY WALLET（以下稱「本 App」，包含 Android、Windows 及 Linux 版）如何在裝置上處理資料，以及在何種情境下將資料送往第三方。相關名詞如「使用者」「持有人」「發證端（發行端）」「查驗方」及「第三方服務」，依「用戶協議」第 2 節定義。

本政策為透明說明 App 實際資料流程、保存及使用者選擇而制定，並參照臺灣地區現行《個人資料保護法》所重視的告知與當事人權益原則。是否因特定處理活動而由開發者或其他營運者承擔法定個資義務，仍應依實際控制、取得與使用資料的事實及適用法律認定；本政策不以文字預先排除依法應負的責任，也不代表所有第三方均由開發者控制。

本 App 的資料流程與開發者透過 GitHub Issues、電子郵件直接接收你提供的資訊，屬不同情境；第三方另有自己的隱私權政策與法定義務。

## 2. 開發者實際取得的資料

本 App 不要求建立開發者帳號；依目前設計，不含廣告、應用程式使用分析、當機回報或使用者追蹤 SDK，也不會預設把錢包內的證件、私鑰、文件或互動紀錄上傳到開發者營運的伺服器。本 App 沒有預設的自有後端；使用者自行填入的服務端不是開發者當然營運的服務。

你若主動透過 GitHub Issues 或電子郵件聯絡，開發者會取得你提供的名稱、聯絡資訊、問題描述及附件，並可能依解決問題與安全通報之合理需要使用和保存；GitHub、電子郵件服務提供者也會依各自政策處理。請勿在公開 Issues 張貼身分證號、憑證、金鑰、私人文件或其他敏感內容。你可透過原聯絡管道提出與該聯絡資料有關的請求，開發者將依適用法律及實際持有情況處理。

即使開發者不接收錢包資料，只要 App 依功能把資料從裝置傳出，Google Play 資料安全申報仍可能將該傳送視為「收集」；這與開發者是否親自保存資料是兩個不同問題。

## 3. 本機保存的資料及用途

- **證件與憑證資料：** 數位證件、識別欄位、照片或卡面圖片、發證資訊、狀態查詢結果與自行簽發的衍生憑證。
- **私鑰與保護資訊：** 錢包及簽署所需的私鑰；Android 優先使用可用的 Android Keystore／StrongBox，否則可能以 App PIN 保護軟體金鑰。安全能力依裝置及使用的金鑰類型而異。
- **電子文件與驗證資料：** 匯入或下載的 PDF、電子公文、OpenCerts 等檔案，以及簽章、憑證鏈、時戳、撤銷資訊、驗證結果、zkPDF 證據等。
- **互動紀錄：** 對象、互動時間、使用的證件及揭露欄位名稱；依目前設計不在此紀錄保存欄位值。證件或文件本身仍可能含有完整個資。
- **設定與快取：** 使用者自行選擇保存的 MyData 身分證統一編號與出生日期、使用者自行指定的服務端位址、信任清單與翻譯快取等。
- **法律文件同意紀錄：** 每份文件版本、同意或不同意的結果及時間，只保存於裝置。

這些資料用於本機顯示、查驗、簽署、信任判斷、功能設定及保留你的選擇。資料原則上位於 App 私有儲存空間，Android 版以裝置金鑰、電腦版以 App PIN 所提供的保護機制加密；並非每種金鑰在所有設備上均可使用硬體隔離。Android 版已停用本 App 的系統自動備份；你主動匯出文件、使用其他備份工具或交付第三方時，不在此限制範圍內。

## 4. 裝置以外的資料傳送

資料傳送發生於使用者發起相關操作，或本 App 為完成證件／文件狀態、信任判斷及其他已啟用功能而執行必要查詢時；並非所有查詢都需要每次另外按下出示確認。連線對象通常能取得來源 IP 位址、連線時間及請求內容，並可能據此推知持有證件的發證單位。其實際保存期限與用途依接收者的政策與法規決定。

- **領取證件：** 傳送授權所需資料、持有者 DID 或公鑰、金鑰證明及發證端所要求的資訊；你在發證端網頁填寫的資料由相應網站接收。
- **出示證件與查驗：** 依選擇向查驗方或對方裝置傳送憑證、你同意揭露的欄位、持有者識別資訊、協定必要資訊及出示證明；QR Code、NFC 或藍牙可能作為建立連線或直接傳送資料的媒介。不同協定可能揭露不同的中繼資料，不應將「只傳選擇的欄位」理解為完全沒有其他必要協定資料。
- **狀態、發證資訊及信任查詢：** 可依設定向發證端、DID 主機及第三方發布者取得憑證狀態、DID 文件、OCSP、CRL、發證端資訊、Adobe AATL、歐盟 EUTL、mdoc 信任清單及測試用信任錨點；部分查詢會自動發生，部分更新可在設定關閉。
- **文件時戳：** 向你選擇的時戳機構（預設為 DigiCert）傳送時戳請求，其中含待處理文件內容計算出的 SHA-256 雜湊值，不傳送完整文件；請求亦可能包含協定必要欄位。
- **文件簽署：** 本機憑證卡可在裝置上進行簽章。遠端 CSC 服務可能收到待簽雜湊值、說明文字（可能含檔名）、登入或授權資訊。行動自然人憑證簽署另見其專門聲明。
- **OpenCerts 線上查驗：** 向公開以太坊節點與 DNS over HTTPS 查詢服務傳送證書儲存庫或網域相關查詢；在你選擇「發證機構樣式」後，整份證書會經 HTTPS 傳給證書指定的顯示網站，該網站可能含第三方程式及自己的資料處理方式。
- **DID 解析：** 遇到 `did:ion` 等需要外部解析的情況時，可向 Microsoft DID 解析服務或相關主機請求 DID 文件。
- **外部文件網站：** 你在 App 內瀏覽器開啟政府或其他文件來源網站時，由該網站直接接收你所輸入的資料；本 App 保存你主動下載或匯入的檔案。
- **零知識證明：** zkPDF 等證明可在裝置上運算；使用 zkTLS 或其他需連線的流程時，可能連線目標網站、公證、中繼或查驗服務，傳送證明、必要協定資訊及你同意提供的資料。特定證明或證據格式可能包含文件內容或簽署版本，不能概括視為絕不傳送文件。
- **自行設定的服務端：** 沒有預設服務端。你自行填入服務端位址並使用其功能時，該營運者可能接收中繼訊息、zkTLS 查驗資料、存取權杖，或行動自然人憑證簽署所需的身分證統一編號、檔名相關說明、簽署屬性與回傳憑證等。傳送是否可被服務端讀取，視具體功能及加密方式而定。
- **系統 Credential Manager：** Android 版可在裝置上向 Android／Google Play 服務的系統選擇器登錄可出示證件的名稱、圖片及顯示欄位，使其他 App 或網站能要求使用證件。此處為裝置系統整合，並非表示資料必然已上傳開發者伺服器。

上述功能可能涉及姓名、電子郵件地址、身分證統一編號與其他使用者識別碼、地址、出生日期、國籍、性別、照片、檔案和文件等；若你選擇傳送的證件或文件本身含有財務、健康等資訊，接收方也可能因此取得相關內容。是否須在應用程式商店申報特定資料類別，應依實際傳送內容與平台定義判定。

## 5. 傳輸方式與剩餘風險

大部分線上領取、出示及遠端簽章連線使用 HTTPS，ISO/IEC 18013-5 的近距離出示依相關協定建立加密通道。但**並非所有傳輸均經過傳輸層加密**：

- 部分時戳、OCSP、CRL、憑證或相關查詢可能使用第三方提供的 HTTP 位址，旁觀者可能知道請求的對象、憑證序號或雜湊等資料，也可能干擾傳輸；簽署的回應可輔助完整性驗證，但不表示所有 HTTP 內容皆安全或能保護查詢隱私。
- 與 Bonds 格式相容的部分藍牙或區域網路離線出示，不提供連線層加密；附近或同區網的第三人可能攔截你揭露的欄位，應避免用於不可信的環境或傳送高敏感資訊。
- 使用者指定的測試服務或本機／區域網路端點，可能允許 HTTP；是否能安全使用取決於網路環境。

開發者會以程式設計上的安全措施降低風險，但不保證所有第三方通訊或接收端均符合相同的安全標準。

下列整合須先閱讀及選擇是否同意各自的專門聲明：數位發展部數位憑證皮夾（TWDIW）、Microsoft Entra Verified ID、內政部行動自然人憑證，以及數位發展部 MyData。zkPassport 相容功能另有專門聲明，列出已提供的部分；未實際提供的功能不因預先展示文字而啟用。

不同意或撤回某份專門聲明，只停止該特定整合的後續連線與功能，其他相容標準的功能仍可使用。先前已保存的證件或文件原則上保留在裝置內；先前傳給第三方的資料與已完成的簽署、出示或申請，不會因撤回而自動刪除或失效。你可在「設定 > 法律聲明與同意」重新選擇。

## 7. 裝置權限

- **相機：** 用於掃描 QR Code。
- **NFC：** 用於感應讀取憑證卡，以及近距離出示或查驗。
- **藍牙：** 用於近距離傳輸；Android 11 以下系統可能另要求位置權限以使用藍牙功能，但本 App 不以該權限讀取或記錄地理位置。
- **生物辨識：** 用於裝置上的使用者確認；本 App 不另行取得或保存生物特徵範本。
- **USB：** 用於連接相容的晶片讀卡機。
- **網路：** 用於上述由你發起或功能所需的第三方連線。

拒絕個別權限可能使相應功能不可使用，通常不影響其他功能。權限需求依作業系統與版本而異。
