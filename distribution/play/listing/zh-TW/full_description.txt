DIW MY WALLET 是開放原始碼的整合數位皮夾：在同一個 App 內領取與出示數位憑證、查驗他人的證件、保存並檢查簽章文件、以自然人憑證或遠端簽章服務簽署，並以零知識證明只交出必要的結論。

【數位憑證】
・領取：OpenID4VCI 1.0 與舊版草案，支援 ISO mdoc、SD-JWT VC 與 W3C VC（含 bbs-2023 選擇性揭露）
・出示：OpenID4VP 1.0、ISO/IEC 18013-5 近距離出示（NFC、藍牙、QR Code）與 Digital Credentials API（瀏覽器與其他 App 可要求出示或存入證件）
・相容台灣數位憑證皮夾（TWDIW）、Microsoft Entra Verified ID、EUDI Wallet 參考實作、Multipaz 與 Bonds 的發證端與查驗端
・出示前顯示查驗方身分、信任等級、用途、請求風險與要交出的欄位，由你決定是否同意
・憑證狀態依規格原文顯示（Token Status List、Bitstring Status List 等）

【查驗】
・以自己的查驗方身分發出線上查驗（OpenID4VP）或近距離 QR 加藍牙查驗，請求附簽章的查驗方聲明
・以 NFC 或讀卡機讀取 mdoc，查驗離線挑戰、年齡證明與 zkPassport 護照證明

【文件與簽章】
・保存並檢查 PAdES、CAdES、XAdES、ASiC、OFD 與電子印章、電子公文簽核檔、RFC 3161 時戳、OpenCerts、OpenPGP 與圖片的 C2PA 內容憑證
・每個簽章分別顯示完整性、憑證鏈信任（一路顯示到根憑證）、時戳與簽署後的變更
・以自然人憑證卡（NFC）、PIV 卡、OpenPGP 卡、PKCS#12 或 CSC 遠端簽章服務簽署，可選 B-B 至 B-LTA 保證層級與可見簽章
・自動加時戳並保存撤銷資訊，同類文件可並存並依年度整理
・讀取電子護照晶片並做被動驗證
・從 MyData 等網站取件，把文件轉成可出示的衍生憑證

【零知識證明】
・年齡證明：只證明「已滿某個年齡」，不交出生日
・網站查驗證明（zkTLS）、mdoc 零知識出示與已簽署 PDF 的欄位證明（zkPDF，手機上較慢）
・zkPassport：以電子護照查驗他人或回應零知識證明請求
・證明預設在你的裝置上產生，也可以交給你自己的電腦產生；需要的電路參數從專案的 GitHub Release 下載並核對雜湊，不下載程式碼

【隱私】
・證件、文件與金鑰只加密保存在你的裝置
・只有在你同意出示、領卡或簽署時，才把必要的資料傳給你選擇的發證端、查驗方或簽章服務；OpenCerts 證書選擇「以發證機構樣式顯示」時，證書內容會送到發證機構的顯示程式
・沒有廣告，沒有分析或追蹤 SDK，不需要註冊帳號
・紀錄只記欄位名稱，不記內容

【語言與平台】
・介面提供繁體中文、簡體中文與英文
・Windows 與 Linux 電腦版可從 GitHub 下載
