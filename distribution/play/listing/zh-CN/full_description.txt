DIW MY WALLET 是开放源代码的集成数字皮夹：在同一个 App 内领取与出示数字凭证、查验他人的证件、保存并检查签章文档、以自然人凭证或远程签章服务签署，并以零知识证明只交出必要的结论。

【数字凭证】
・领取：OpenID4VCI 1.0 与旧版草案，支持 ISO mdoc、SD-JWT VC 与 W3C VC（含 bbs-2023 选择性揭露）
・出示：OpenID4VP 1.0、ISO/IEC 18013-5 近距离出示（NFC、蓝牙、QR Code）与 Digital Credentials API（浏览器与其他 App 可要求出示或存入证件）
・兼容台湾数位凭证皮夹（TWDIW）、Microsoft Entra Verified ID、EUDI Wallet 参考实作、Multipaz 与 Bonds 的发证端与查验端
・出示前显示查验方身分、信任等级、用途、请求风险与要交出的字段，由你决定是否同意
・凭证状态依规格原文显示（Token Status List、Bitstring Status List 等）

【查验】
・以自己的查验方身分发出在线查验（OpenID4VP）或近距离 QR 加蓝牙查验，请求附签章的查验方声明
・以 NFC 或读卡机读取 mdoc，查验离线挑战、年龄证明与 zkPassport 护照证明

【文档与签章】
・保存并检查 PAdES、CAdES、XAdES、ASiC、OFD 与电子印章、电子公文签核档、RFC 3161 时间戳、OpenCerts、OpenPGP 与图片的 C2PA 内容凭证
・每个签章分别显示完整性、凭证链信任（一路显示到根凭证）、时间戳与签署后的变更
・以自然人凭证卡（NFC）、PIV 卡、OpenPGP 卡、PKCS#12 或 CSC 远程签章服务签署，可选 B-B 至 B-LTA 保证层级与可见签章
・自动加时间戳并保存撤销信息，同类文档可并存并依年度整理
・读取电子护照芯片并做被动验证
・从 MyData 等网站取件，把文档转成可出示的衍生凭证

【零知识证明】
・年龄证明：只证明「已满某个年龄」，不交出生日
・网站查验证明（zkTLS）、mdoc 零知识出示与已签署 PDF 的字段证明（zkPDF，手机上较慢）
・zkPassport：以电子护照查验他人或回应零知识证明请求
・证明默认在你的设备上产生，也可以交给你自己的电脑产生；需要的电路参数从项目的 GitHub Release 下载并核对哈希，不下载代码

【隐私】
・证件、文档与密钥只加密保存在你的设备
・只有在你同意出示、领卡或签署时，才把必要的数据传给你选择的发证端、查验方或签章服务；OpenCerts 证书选择「以发证机构样式显示」时，证书内容会送到发证机构的显示程序
・没有广告，没有分析或追踪 SDK，不需要注册账号
・记录只记字段名称，不记内容

【语言与平台】
・界面提供繁体中文、简体中文与英文
・Windows 与 Linux 电脑版可从 GitHub 下载
